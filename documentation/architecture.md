# Lab Architecture

## Purpose

This document will describe the architecture of the Active Directory help desk lab as it is built and verified.

## Planned Environment

The initial environment is expected to contain:

- An AWS VPC
- A Windows Server domain controller (`directory server`)
- Active Directory Domain Services (AD DS)
- DNS
- A Windows client (`Windows client`) joined to the domain

The final architecture will be documented with an original diagram and configuration details.
